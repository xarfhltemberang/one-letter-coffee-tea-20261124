## The entry

`main.py` writes exactly one letter to `/output/entry.txt`:

```
A
```

`A` stands for coffee; `B` would stand for tea. The rules allow exactly
one letter and nothing else — no word, no explanation, no punctuation —
and anything else loses to any letter that chooses coffee or tea, so the
entry is one bare letter.

**Choice: A — coffee.** Of the two drinks, coffee is the more vivid,
fuller, more alive answer: the morning jolt, the aroma, the bold stance.
Tea is calm; coffee lands.

## Running it

```sh
python3 main.py   # writes "A" to /output/entry.txt
```

Python 3.13, standard library only. No network, no secrets, no input
files — everything the entry runs is in this repository.
